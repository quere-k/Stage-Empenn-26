# Stage-Empenn-26

The aim of this internship is to improve acquisition schemes in diffusion MRI (dMRI) for parameter estimation using neural networks and dictionary-based representations. Two different models for signal fitting are used : a signal representation and a three-compartment tissue model.

## Content
- Model 1 : 
    - neural networks without selection layer
        - data-driven
        - parameter
        - equation
    - concrete autoencoders :
        - data-driven
        - parameter
        - equation
    - dictionary :
        - dataset division
        - subset optimization
    - parameter estimation
- NODDI model :
    - concrete autoencoders :
        - data-driven
        - parameter
    - dictionary :
        - dataset division 
        - subset optimization 4 and 2 shells
    - parameter estimation 4 and 2 shells

## Models
- Stejskal-Tanner diffusion equation : $S=S_0e^{-bD}$
- NODDI model
